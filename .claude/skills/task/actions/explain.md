# explain

1. Pročitaj task i `git diff main --name-only`.
2. Za svaki fajl: putanja, (novo/izmijenjeno), 1–2 rečenice šta radi i zašto je dirnut.
3. Posebno izdvoji generisane fajlove — reci iz kojeg ulaza su nastali, da čitalac ne pokuša
   pregledati ih kao ručno pisan kod.
4. Zatvori sa "kako se dijelovi vežu": tok od ulaza (tenant.yaml, migracija, ekran) do dokaza (CI
   job, artefakt, test).

Format:

## Promijenjeni fajlovi
**putanja** (novo) — šta radi.

## Kako se to veže
Tok podataka/kontrole u par rečenica.
